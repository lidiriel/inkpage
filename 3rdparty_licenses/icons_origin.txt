Origin of the icons replaced in inkpage
=======================================

The interface icons of inkpage come from PDF4QT (MIT, see PDF4QT_LICENSE), except the
files listed below, which were taken from other free icon sets. The other icons are
unchanged PDF4QT icons. Each replaced SVG file also starts with a comment giving its
origin and license.

Summary of the licenses (all compatible with the GNU GPL version 3, the license of inkpage):
- FreeCAD (https://www.freecad.org): LGPL-2.1-or-later, see icons_FreeCAD_LGPL-2.1.txt;
  Draft_Ellipse and colors are also marked CC-BY-SA-4.0, see icons_CC-BY-SA-4.0.txt
- Xournal++ colour icons (https://github.com/xournalpp/xournalpp): GPL-3.0-or-later,
  see icons_Xournalpp_GPL-3.txt
- Numix icon theme (https://github.com/numixproject/numix-icon-theme): GPL-3.0-or-later,
  see icons_Numix_GPL-3.txt
- Papirus icon theme (https://github.com/PapirusDevelopmentTeam/papirus-icon-theme):
  GPL-3.0-only, see icons_Papirus_GPL-3.txt (while these icons are included, inkpage as a
  whole is distributed under the GPL version 3)
- Tango icon theme 0.9.0 (https://git.golem.linux.it/matteobin/tango-icon-theme): CC0-1.0
  (public domain), see icons_Tango_CC0-1.0.txt
- Flat Color Icons by Icons8 (https://github.com/icons8/flat-color-icons): MIT,
  see icons_FlatColor_MIT.txt
- MATE icon theme (https://github.com/mate-desktop/mate-icon-theme): LGPL-3.0-or-later,
  see icons_MATE_LGPL-3.txt
